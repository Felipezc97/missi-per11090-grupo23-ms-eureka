# 🧭 Eureka Service Discovery

### Descripción
Servicio de descubrimiento de servicios para una arquitectura de microservicios, desarrollado con Java y Spring Boot. El repositorio contiene `pom.xml`, un `Dockerfile` y el código de la aplicación.

### ⚙ Requisitos
- Java y Maven, en versiones compatibles con `pom.xml`.
- Docker, si deseas construir y ejecutar la imagen del servicio.

### 🚀 Instalación y uso
```bash
git clone https://github.com/Felipezc97/missi-per11090-grupo23-ms-eureka.git
cd missi-per11090-grupo23-ms-eureka
```
Consulta la configuración de la aplicación para verificar los parámetros del entorno. Puedes ejecutar el servicio desde tu IDE o construirlo con Maven usando `mvn clean package`.
